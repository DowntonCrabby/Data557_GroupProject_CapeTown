## Running the Interactive Data Story in Google Colab

The interactive analysis notebook can be run directly from this repository using Google Colab, which allows you to execute the Jupyter notebook without installing Python locally.

---

### Step 1: Open the Notebook in Colab

Navigate to the notebook located at:

```
Data557_FinalProject_Q2_DataStory.ipynb
```

Click **Open in Colab** at the top of the notebook preview.

![Open Notebook in Colab](./readme_images/open_in_colab.png)

This will launch the notebook in a new Google Colab session.

---

### Step 2: Download the Dataset

The notebook uses the cleaned dataset located in this repository:

```
cleaned_longitudinal_dataset.csv
```

Open the dataset file in GitHub and click **Download raw file**.

![Download Dataset](./readme_images/download_raw_dataset.png)

Save the file to your local machine.

---

### Step 3: Upload the Dataset to Colab

In the Colab environment, open the **Files panel** on the left side of the screen and upload the dataset file you downloaded.

Drag the dataset into the upload area or use the upload button.

![Upload Dataset](./readme_images/upload_dataset_colab.png)

Once uploaded, the file will appear in the Colab file browser and the notebook will be able to load it.

---

### Step 4: Run the Notebook

After uploading the dataset, run the notebook using:

```
Runtime → Run All
```

This will execute the full analysis, figures, and statistical models used in the project.
